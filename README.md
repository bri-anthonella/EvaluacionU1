# EvaluacionU1
##¿Qué es una rama?
Una rama en GitHub Desktop es una versión alternativa del proyecto donde puedes trabajar en cambios sin afectar el código principal. Sirve para desarrollar nuevas funciones, corregir errores o probar ideas de forma segura.

##¿Qué es la rama main?

La rama main es la rama principal de un repositorio en Git y GitHub. Es donde generalmente se mantiene el código estable y listo para producción. Todas las nuevas funciones o correcciones se suelen desarrollar en otras ramas y luego se integran (merge) a la rama main.
